# 数据清洗规则

## 多选题

只有 `┋` 作为多选值分隔符。`/`、顿号、逗号、分号和 `|` 均视为普通文本，不用于自动判定或拆分多选题。

例如，`高中/中专/职校/技校` 是一个完整的学历选项；`抖音┋线下门店` 才是两个多选值。

## 排序题与数值字段

只有 ASCII 字符 `->` 作为排序题分隔符；Unicode 箭头 `→` 和其他符号不会自动判定为排序题。纯数值字段默认推荐使用箱型图展示最小值、四分位数、中位数和最大值。

## 从事行业

导入 XLSX、XLS、CSV 或 JSON 数据时，如果字段名同时包含“从事”和“行业”，系统会在字段类型识别前自动归一化该列。原始文件不会被修改。

标准分类共 17 类：

- 公共管理与事业单位
- 制造与工业服务
- 商贸零售与个体经营
- 建筑与房地产
- 教育培训
- 信息技术与互联网通信
- 住宿餐饮与生活服务
- 医疗健康与社会服务
- 金融与财会
- 能源矿产与公用事业
- 交通物流与邮政
- 科研与专业服务
- 农林牧渔
- 文化体育娱乐与旅游
- 水利环境与公共设施
- 自由职业（行业未明确）
- 未就业/学生
- 退休
- 租赁服务
- 其他

归类采用明确行业关键词优先。以下内容统一归入“其他”：

- 无法识别或行业信息不足的回答

自由职业但未说明实际行业的回答单列为“自由职业（行业未明确）”；无业、待业、学生、主妇或主夫单列为“未就业/学生”；水利、环境与公共设施管理单列为“水利环境与公共设施”。退休、离休等回答单独归入“退休”。已经是上述标准分类的数据保持不变。
